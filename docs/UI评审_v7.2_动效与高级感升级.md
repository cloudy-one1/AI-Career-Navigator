# UI 评审报告 v7.2 — 动效感与高级感升级

> 评审视角：产品架构师 + 视觉/交互设计师
> 评审对象：v7.1 全站「纸墨印章」UI（DOM/类名不动、Token 重映射换肤方案）
> 结论先行：**信息架构与视觉基底是合格的，真正拉低质感的是「双主题审美割裂 + 零过渡硬切 + 无编排的碎片动效」三件事。**

## 二、问题清单（按影响排序，均附证据）

### P0-1 双主题审美割裂（最大失分点）
- 浅色：纸墨印章（`--paper:#F4F2ED` + `--stamp:#C44F3A`），文人感、克制。
- 深色：`--bg-page: linear-gradient(135deg,#1C1F3B,#16213E,#1A1040)` + 青/粉/金/紫四色 + **语义色切换器**（`theme.css:144-164`、`themeToggle.js` ACCENTS 表）。
- 问题：①两套主题色相环上完全不相交，品牌记忆无法沉淀；②深色下 token 重映射把印章红→紫、黄铜→蓝，纸墨母题清零；③给用户四种语义色选择是「不自信」的信号——高级产品替用户做好决定。

### P0-2 面板切换零过渡
- `.panel { display:none } .panel.active { display:block }`（`style.css:9-10`），11 个 Tab 硬切。
- 这是用户感知「廉价感」的第一来源：内容瞬移、无方向感、无连续性。

### P0-3 加载态全是 spinner
- `loading-spinner` 遍布 report/careerPlan/recruiterInbox/shareReport/history，市场页另造一套 `mkt-spinner`。
- spinner 表达的是「系统很忙」，骨架屏表达的是「内容马上来」。全 spinner = 廉价感重灾区。

### P1-4 动效碎片化、无编排（choreography 缺位）
- 20+ keyframes 各页自造（`intvSlideIn`/`popIn`/`speakerPulse`/`dotPulse`/`authCardIn`/`mktFadeUp`…），时长/缓动虽有三档 token 但没有「入场编排队列」：同屏元素应 stagger 错峰（60ms 间隔），而不是同时闪现。
- 没有「仪式感动效」：评分揭晓、分享生成、登录成功这类高光时刻与普通 hover 同权重。

### P1-5 微交互深度不足
- 只有 `card-hover`(translateY -2px) 与 `btn-press`(scale 0.98) 两式（`style.css:31-42`）。
- 缺：数字滚动（评分环直接跳变）、环形描边动画、印章「盖章」确认、表单错误 shake、进度条流光。

### P1-6 信息架构扁平
- 侧边栏 11 项无分组（`index.html:55-101`）：面试/报告/历史/题库/职业规划/市场/记忆/简历库/岗位库/收件箱/账户平铺，认知负担全给用户。
- 细节：`<title>AI面试官与职业规划 v3.2</title>`、`.version-badge` 仍显示 v3.2，与 CHANGELOG v7.1 脱节。

## 三、升级方案（已实施）

### 3.1 深色主题重设计 ——「墨夜纸墨」
- 底色改为炭墨纸（墨绿灰调 `#141614→#1B1E1B`），延续「纸」母题；印章红提亮为朱砂 `#E06A52`、黄铜 `#C9A961`，与浅色同源。
- **移除四色语义色切换器**，深色改为单一朱砂强调，两主题终于讲同一个故事。

### 3.2 动效基建 `src/css/motion.css`（新增）
- 新 token：`--dur-gesture(200ms)/--dur-reveal(500ms)/--ease-emphasized/--stagger(60ms)`。
- **面板切换**：优先 View Transitions API（Chromium 原生平滑过渡），不支持时降级为 `panel-enter` fade+slide-up；同屏子元素 stagger 错峰入场。
- **骨架屏** `skeletonBlock()`：纸纹 shimmer 扫光，替换 5 处 spinner 场景。
- **仪式感动效**：`stampIn()` 印章盖章（scale 1.6→1 + 旋转回正 + 墨晕扩散）用于登录成功/分享生成；`countUp()` 数字滚动用于评分环与统计卡；`shake()` 表单错误反馈。
- 全部挂 `prefers-reduced-motion` 降级。

### 3.3 信息架构分组
- 侧边栏四组：**面试域**（模拟面试/历史/题库）、**资产域**（简历库/岗位库）、**洞察域**（报告/市场/记忆/职业规划）、**账户**；组间小标题分隔，平板图标栏与移动端底栏不受影响。
- 修正 title 与版本徽章为 v7.2。

### 3.4 页面级仪式感
- 报告页：评分环描边绘制动画 + 分数 countup 滚动。
- 登录页：登录/注册成功印章盖章反馈，表单校验失败 shake。
- 市场页：印章装饰 hover 盖章微交互；诊断进度条流光。

## 四、度量与验收

- 双主题 × 5 核心页截图回归（浏览器实测）。
- `prefers-reduced-motion: reduce` 下全部动效静默。
- 构建无报错；不引入任何新依赖。
