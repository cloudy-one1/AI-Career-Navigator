# Week1 需求文档：问题生成模块（question_gen）

> 模块定位：轻量模块，做浅做轻，单 Agent 一次性生成即可。

## 一、模块目标

根据候选人简历 + 岗位描述（JD），一次性生成 **5-8 道**针对性面试题，并提炼 JD 关键词，为后续诊断引擎提供"题面"输入。

题目要求：
- 覆盖技术深度、项目经验、行为面试（STAR）等维度；
- 结合简历中的具体项目经历，而非泛泛而谈；
- 有追问空间，但本模块不生成追问。

## 二、当前实现状态（骨架已就绪）

文件：`backend/question_gen.py`，已实现 `generate_questions(llm_client, resume_text, jd_text)`：

- `SYSTEM_PROMPT`：设定"资深技术面试官"角色，规定工作步骤（先提取 JD 关键词 → 再出题）与 JSON 输出格式。
- 输出契约：`{"keywords": [...], "questions": [{"index": 0, "question": "..."}, ...]}`。
- 调用参数：`resume_text` 截断 3000、`jd_text` 截断 2000，`temperature=0.7` 保证题目多样性，`max_tokens=2048`。

## 三、技术方案

- **单 Agent 一次性生成**（符合"轻量"定位）：不拆分多 Agent，prompt 内用"步骤引导"完成"提取关键词 + 出题"两件事。
- **关键词前置**：先让模型从 JD 抽取 5-8 个关键词，作为出题的锚点，提升题目与岗位的相关度。
- **题目三维度**：技术深度 / 项目经验 / 行为（STAR），prompt 中显式要求覆盖。
- **结构化输出**：强制仅输出 JSON，前端可直接渲染题目列表。

## 四、涉及的知识点

- 单 Agent Prompt 设计（角色 + 步骤 + 格式约束）。
- LLM 结构化 JSON 输出与解析。
- 面试题目设计方法论（技术/项目/行为三维）。
- 文本截断与上下文成本控制（resume/jd 截断长度）。
