>
> | 类别 | 是否随仓库公开 | 内容 |
> |---|---|---|
> | **公开文档** | ✅ 入库 | 能让外部读者看懂、上手、复用项目的文档 |

> 过程性资料由 `.gitignore` 排除（**不删除**，只是不跟踪）。本地目录结构与索引见本文件第三节。

## 四、文档约定

1. **新增文档先问一句"外部读者需要它吗"**：需要 → 放 `docs/` 根并更新本索引；不需要（过程稿 / 调研 / 验收材料）→ 放进 `docs/archive/` 或 `docs/research/`，自动不公开。
2. **公开文档里不要链到过程性资料**——那些链接在 GitHub 上会 404（本地正常）。需要提及时用纯文本写文件名并注明「本地文档」。
3. 二进制产物（docx / pdf / pptx）一律放子目录，依赖 `.gitignore` 的扩展名规则，**不放 `docs/` 根**。
4. 过程性资料与公开文档的划分不写死：若后续要把仓库当作业提交，把 `.gitignore` 里对应条目删掉即可恢复跟踪。
